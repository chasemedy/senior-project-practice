# Senior Project Developer Profile

A simple Python program that prints a short developer profile for Senior Project.

## What it displays

- Name
- Major
- Technology Interest
- Skill Goal

## Requirements

- Python 3

## How to run

From the folder containing `app.py`:

```
python app.py
```

## Example output

```
Senior Project Developer Profile

Name: Chase Medy
Major: Computer Science
Technology Interest: Green Software Engineering
Skill Goal: Software Architecture
```

## Editing your profile

Open `app.py` and change the values near the top of the `main()` function:

```python
name = "Chase Medy"
major = "Computer Science"
technology_interest = "Green Software Engineering"
skill_goal = "Software Architecture"
```
